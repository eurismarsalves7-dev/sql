# Projeto 01 — Análise de Vendas e Performance Comercial com SQL

Projeto acadêmico desenvolvido durante a formação em Ciência de Dados.

## Objetivo
Utilizar SQL para analisar performance de vendas, produtos, vendedores e regiões a partir de um banco de dados relacional.

## Tecnologias
- SQL
- PostgreSQL
- CTEs
- Window Functions
- Modelagem Relacional

## Estrutura de dados
O projeto documenta tabelas de clientes, produtos, categorias, vendedores, pedidos e itens de pedido.

## Metodologia
1. Modelagem do esquema relacional.
2. Criação de chaves primárias e estrangeiras.
3. Carga e validação de dados.
4. Consultas com JOIN, GROUP BY e agregações.
5. CTEs para consultas complexas.
6. Window Functions como RANK, ROW_NUMBER, LAG e SUM OVER.
7. Criação de views para indicadores recorrentes.
8. Documentação das queries e resultados.

## Resultados documentados
A análise contemplou ranking de produtos e vendedores, evolução do ticket médio e desempenho regional.
